# Addons Studio Alpha 0.0.3.6.3

## Model Core Architecture & Stabilization

Alpha `0.0.3.6.3` is the engineering stabilization release after Snapshot 3. It deliberately freezes the first-generation Model Core feature scope and focuses on making the existing editor safer to maintain before Texture Core development begins.

## Highlights

- Model Studio's Three.js runtime is split into focused modules for scene lifecycle, camera, cuboid rendering, classic gizmos, Touch Gizmo, Inflate, selection helpers, shared viewport math, and resource disposal.
- `StudioModel` remains the renderer-independent source of truth. The refactor does not serialize or persist Three.js objects.
- Touch Gizmo Rotate is promoted from experimental to an official Touch Gizmo interaction alongside Move and Resize.
- Editor environment backgrounds and viewport-aligned modeling guides are rendered through one Background / Guide layer while existing guide data remains compatible.
- Studio Preview Material 2.0 uses an original generated pixel-inspired texture with nearest-neighbor sampling and stable muted variants for clearer untextured geometry.
- Shared touch deadzone and large invisible picker targets preserve finger-first selection without making visible gizmos oversized.
- Existing transform-spike safeguards, low-power split viewport behavior, iPhone-safe inputs, and runtime cleanup are preserved and covered by architecture regression tests.

## Data safety

This update does not reset IndexedDB and does not intentionally change the canonical `.model.json` or beta `.addonsstudio` package formats. Existing Alpha `0.0.3.x` project/model migration behavior remains part of the release boundary.

## Still out of scope

- Texture Core / UV mapping / painting
- real project materials
- Animation Core / bones / timeline / keyframes
- particles and audio editors
- visual logic
- complete `.mcpack` / `.mcaddon` generation

The next major product development line is planned as Alpha `0.0.4` — Texture Core after Model Core stabilization is accepted.
