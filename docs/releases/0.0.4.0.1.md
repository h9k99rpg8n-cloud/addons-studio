# Addons Studio Alpha 0.0.4.0.1

## Visual Texture Workspace Update

Alpha `0.0.4.0.1` is the first Texture Core polish release. It keeps the `0.0.4.0` persistence model and project-scoped material library, but redesigns the texture workflow around a touch-first visual editor instead of form-heavy controls.

## Texture Core

- The editor is now a vertical mobile workspace with a real 3D preview, a draggable workspace divider, contextual Material / UV / Paint modes, and a bottom tool switcher placed near the user's thumb.
- The 3D preview now fits the real model bounds instead of using one coarse camera distance.
- Tapping geometry selects a cuboid and identifies the touched face as North, South, East, West, Up, or Down.
- The selected face is highlighted in the 3D preview and connected directly to the UV workspace.
- Cubes can also be selected from a compact visual strip without leaving the viewport.

## Visual UV workspace

- UV mapping is no longer represented only by dropdowns and text values.
- The selected face appears as a visible UV island over the texture image.
- Dragging the island moves it with 1-pixel precision.
- A large touch handle resizes the island.
- Rotate 90°, horizontal flip, vertical flip, and Fit are available contextually.
- UV edits are clamped to the texture bounds and persisted independently from model geometry.
- Existing per-face bindings remain compatible.

## Paint

- Paint tools are arranged contextually for mobile instead of being mixed with Material and UV controls.
- Pencil, Eraser, Fill, Eyedropper, and Pixel Inspect are available.
- The old permanent zoom slider is removed from the main workflow.
- Pinch gestures change canvas zoom and two-finger movement pans the texture workspace.
- Inputs use iPhone-safe editable text sizing where relevant.

## Materials

- Materials now behaves as a visual project library rather than a long settings form.
- Reusable materials remain project-scoped and can still be shared by multiple models.
- Material spheres/swatches remain the visual identity for reusable textures.
- Quick Edit uses the same touch-first paint controls and pinch workflow as Texture Core.

## Scope

This update does not begin Animation Core, Audio Core, Visual Logic, plugin APIs, or arbitrary mesh UV editing. It is a visual and usability stabilization release for the first Texture Core generation.
