# Alpha 0.0.4.2 — Texture Core 0.2

This release completes the second major Texture Core content pass before the 0.0.4.3 stabilization line.

## UV 2.0

- Visual UV atlas for all faces of the selected cuboid that use the active material.
- Direct 3D face selection remains synchronized with the UV workspace.
- Multi-face selection for applying one material to several faces.
- Auto Box UV generated from the real cuboid X/Y/Z dimensions.
- UV precision presets: 0.25 px, 0.5 px, 1 px, 2 px, and 4 px.
- Copy, Paste, Rotate 90°, Flip X/Y, Fit, and Reset controls.
- Batch UV persistence so multiple faces can be updated atomically.
- UV islands remain clamped to the texture bounds.

## Paint 2.0

Paint is now a dedicated module instead of living inside the main Texture Core view.

- Pencil, Eraser, Fill, Eyedropper, Pixel Inspect.
- Line and Rectangle tools.
- Replace Color tool.
- Mirror Paint on X, Y, or both axes.
- 25/50/75/100% opacity.
- 1/2/4/8 px brush sizes.
- Optional pixel grid.
- Pinch zoom and touch panning.
- 64-step Undo/Redo history.
- PNG save back into the project material library.

## Materials workflow

- Create blank 16×16, 32×32, 64×64, or 128×128 textures directly from Texture Core.
- Apply the current material to one face, a multi-face selection, or the whole cuboid.
- Materials remain project-scoped and reusable across models.

## Architecture

`TextureCoreView.vue` is now primarily an orchestrator. UV editing and painting are isolated so the planned 0.0.4.3 stabilization release can fix one subsystem without destabilizing the other.

## Next

Alpha 0.0.4.3 is reserved for bug fixes, Safari/mobile polish, accessibility, performance, and regression hardening. No new major Texture Core feature is required before the project moves into the Materials-focused era.
